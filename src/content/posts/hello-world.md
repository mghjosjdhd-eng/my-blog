## 为什么要写博客？

一直想有一个自己的博客，用来记录学习过程中的思考、踩过的坑、以及解决问题的方法。GitHub 上看到很多开发者的博客，深受启发，于是决定自己也做一个。

## 这个博客是怎么搭建的？

这个博客使用了以下技术：

- **Astro**：现代化的静态站点生成器，构建产物是纯 HTML/CSS，不需要 JavaScript 也能正常浏览
- **Markdown**：所有文章都用 Markdown 写，简洁高效
- **GitHub Actions**：代码推送到 GitHub 后自动构建部署
- **GitHub Pages**：免费托管静态网站

### 搭建过程

整个过程分为几步：

1. 初始化 Astro 项目，安装依赖
2. 创建布局和组件（Header、Footer、PostCard）
3. 实现页面（首页、文章详情、关于页、404）
4. 写示例文章
5. 配置 GitHub Actions 自动部署
6. 推送到 GitHub，启用 Pages
